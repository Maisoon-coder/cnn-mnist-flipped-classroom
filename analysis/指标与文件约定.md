# 5-01 指标与文件约定（组员 4 ⇄ 组员 5）

**用途**：把“日志怎么写、结果怎么存、索引怎么查”固定在开工之前，避免第 3 天出图时才发现字段对不上。
**状态**：本文件依据 H4 实际交付的 `outputs/main_seed42_v1/` 回溯整理并逐项核对通过；
若后续改字段，按第八节的方式通知，不能悄悄改。

---

## 一、目录与命名

```
outputs/<run_id>/
├── config.json              本次冻结配置（含 run_id / seed / data / train / models）
├── environment.txt          Python / torch / torchvision / 设备 / 线程
├── metrics.csv              每轮 × 每个划分的指标，2 模型 × 5 轮 × 2 划分 = 20 行
├── results.csv              2 行汇总（取最后一轮）
├── errors_<model>.csv       全部误判样本，一模型一份
└── checkpoints/
    ├── cnn_seed42_last.pt   {model}_seed{seed}_last.pt
    └── fc_seed42_last.pt
```

- `run_id` 采用 `main_seed{seed}_v{版本号}`，本次为 `main_seed42_v1`。
- 权重文件名必须含模型名与种子，末尾 `_last` 表示“最后一轮”，不表示“最好的一轮”。
- 改种子、轮次或训练配置 → **新建 run_id**，不覆盖旧目录（细则 §8.3）。

## 二、metrics.csv 字段

| 字段 | 含义 | 精度 / 取值 |
|---|---|---|
| `run_id` | 实验编号 | 字符串 |
| `model` | 模型名 | `fc` / `cnn` |
| `seed` | 随机种子 | 整数，本次 42 |
| `epoch` | 轮次 | 1—5 |
| `split` | 划分 | `train` / `test` |
| `n_samples` | 该划分样本数 | 60000 / 10000（末尾短 batch 不丢） |
| `loss` | 样本加权平均 loss | 6 位小数；**按样本数加权**，不是各 batch 均值再平均 |
| `accuracy` | 正确数 / 总数 | 6 位小数存储，图上按百分数显示 2 位 |
| `train_seconds` | 该轮训练墙钟秒 | 1 位小数，仅 `split=train` 行有值 |

行序约定：同一模型先 `train` 后 `test`，按 epoch 递增。

## 三、results.csv 字段

`run_id, model, seed, epoch, n_params, test_acc, test_loss, n_samples, checkpoint`

- `test_acc` / `test_loss` 保留 6 位小数（与 metrics 的 test 行一致，便于逐位比对）。
- `n_params` 为**整网可训练参数含偏置**：FC 203,530 / CNN 61,706。
- `checkpoint` 为相对 `run_dir` 的路径，跨机器可读。

## 四、errors_\<model\>.csv 字段

`index, true_label, pred_label, prob_true, prob_pred, margin`

| 字段 | 约定 |
|---|---|
| `index` | **`datasets.MNIST(train=False)` 的原始索引**（0—9999）。因此测试加载器必须 `shuffle=False`，否则索引无意义 |
| `true_label` / `pred_label` | 0—9 整数 |
| `prob_true` / `prob_pred` | softmax 后的打分，6 位小数 |
| `margin` | `prob_pred − prob_true` |

⚠️ `prob_pred` 是**模型打分**，不是校准后的置信度，图上与讲稿里都不能说“模型有 x% 的把握”。

## 五、回查原图

## 六、权重文件结构

```python
{"format_version": 1, "model": "cnn", "seed": 42, "epoch": 5,
 "model_state": {...}, "extra": {"run_id": "...", "epochs": 5, ...}}
```

只存裸 `state_dict` 会导致“这份权重是哪次运行的”无法追溯，验收项 A04 会失败。

## 七、展示口径（与细则 §6.4 一致）

| 项目 | 约定 |
|---|---|
| 轮次 | 取**最后一轮**，不按测试集挑 |
| 准确率差 | 用“**百分点**”，如“高 1.81 个百分点” |
| 参数量变化 | 用相对百分比，如“减少 69.68%”“约为 FC 的 30.32%” |
| 每类准确率 | 分母是**该类真实样本数**（测试集不等量：1 有 1135、5 有 892、8 有 974） |
| 耗时 | 只在本机同环境内比较，跨机器不可比 |

## 八、改动怎么通知

| 改动 | 影响 | 谁通知谁 |
|---|---|---|
| 重命名 `errors_*` 字段 | 画图脚本全部失效 | 组员 4 → 组员 5，附新旧对照表 |
| 改 `index` 语义（如改用 batch 内序号） | 误判样本无法回查 | 组员 4 → 组员 5，且需重出全部误判图 |
| 改 loss/accuracy 统计方式 | 所有指标与图表失效 | 组员 4 → 组员 5 重算，组员 1 更新结果页 |
| 换种子 / 轮次 / 配置 | 属于新实验 | 新建 run_id，旧目录只读保留 |

本次核对结论：上述字段与 `outputs/main_seed42_v1/` 实际内容**逐项一致**，
5-04 ~ 5-07 的脚本可以不经修改直接从该目录取数。
