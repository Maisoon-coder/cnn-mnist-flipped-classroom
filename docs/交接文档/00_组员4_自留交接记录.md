## 六、答辩预备（6 问）

| 问题 | 答案要点 |
|---|---|
| 为什么要 `zero_grad()` | PyTorch 梯度累加，不清零会叠加上一批的梯度 |
| `backward()` 和 `step()` 区别 | 前者算梯度，后者按梯度改参数 |
| 为什么交叉熵不用 MSE | 分类任务梯度更有效；模型输出是 logits，CE 内部含 log_softmax |
| `eval()` 和 `no_grad()` 是一回事吗 | 不是。前者改 Dropout/BN 行为，后者关梯度记录，通常一起用 |
| 怎么保证可复现 | 三个随机源设种子 + 数据打乱用独立 generator + 记录版本 |
| 存权重和重训什么区别 | 权重只存参数，不存优化器状态，必须配 config 和 run_id 才能追溯 |
