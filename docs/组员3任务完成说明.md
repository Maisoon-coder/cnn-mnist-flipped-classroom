## 四、给组员 4、5 的接口（交接的核心）

| 内容 | 约定 |
|---|---|
| 输入 | `[N, 1, 28, 28]` float32，已标准化（mean=0.1307，std=0.3081） |
| 标签 | `[N]` int64，0—9 |
| 输出 | `[N, 10]` **logits，不含 Softmax** |
| 创建模型 | `build_model("fc")` / `build_model("cnn")` |
| 加载器 | `get_loaders(batch_size=64, seed=42)` → `(train, train_eval, test)` |
| CNN 特征 | `forward_features(x)` → `conv1_relu` / `pool1` / `conv2_relu` / `pool2` |
| 存权重 | `save_checkpoint(model, path, model_name, seed, epoch)` |
| 读权重 | `load_model_from_checkpoint(path)` → 已 `eval()` 的模型 |
| 回查原图 | `get_raw_dataset_by_split("test")[i]`（0—1 像素，可直接显示） |

这三条最容易踩：**输出不要套 Softmax**、**测试集不打乱才能按索引回查**、
**预测必须复用 `build_transform()`**。
