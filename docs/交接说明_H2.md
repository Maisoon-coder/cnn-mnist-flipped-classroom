## 一、组员 4 需要接的三件事

### 1. 训练循环用哪几个入口

```python
from src.data import get_loaders
from src.models import build_model, count_parameters, save_checkpoint

train_loader, train_eval_loader, test_loader = get_loaders(batch_size=64, seed=42, num_workers=0)
model = build_model("cnn")            # 或 "fc"
```

- 三类加载器已替你处理好"打乱/不打乱/末尾短 batch"，**不要再自己写 DataLoader**，
  否则两模型的数据顺序口径会分叉。
- 模型输出是 **logits**，直接 `nn.CrossEntropyLoss()(logits, y)`，**不要再加 Softmax**。

### 2. 权重怎么存

```python
save_checkpoint(model, "outputs/main_seed42_v1/checkpoints/cnn_seed42_last.pt",
                model_name="cnn", seed=42, epoch=5,
                extra={"test_acc": 0.99, "config": "config.json"})
```

存成 dict 而不是裸 `state_dict`，是为了让"权重 ↔ 模型 ↔ 种子 ↔ 轮次"可追溯（验收项 A04）。
`predict.py` 和组员 5 的复评都直接读这个格式。

### 3. 评估口径

- loss 按**样本数加权**累计（不能对不同大小 batch 的均值再平均）；
- accuracy = 总正确数 / 总样本数，训练集 60000、测试集 10000；
- 误判清单至少含 `test_index, true_label, pred_label`，索引直接对应 `test_loader` 的顺序。

## 二、组员 5 需要接的两件事

### 1. 取中间特征画图

```python
from src.models import load_model_from_checkpoint
from src.data import get_dataset_by_split

model, meta = load_model_from_checkpoint("outputs/main_seed42_v1/checkpoints/cnn_seed42_last.pt")
x, y = get_dataset_by_split("test")[1234]        # 已标准化，与训练输入一致
with torch.no_grad():
    feats = model.forward_features(x.unsqueeze(0))
# feats["conv1_relu"] [1,6,28,28] / feats["pool1"] [1,6,14,14]
# feats["conv2_relu"] [1,16,10,10] / feats["pool2"] [1,16,5,5]
```

- 四个键名固定，含义已在 `forward_features` 的 docstring 里写明（卷积后+ReLU后 / 池化后）；
  画图标注不要写成"卷积前"。
- 画图前记得 `.detach().cpu()`；若要纵向对比响应强弱，**不要**逐图单独归一化，
  否则图注必须写明"各图独立缩放，不用于比较绝对响应"。
- 卷积核直接用 `model.conv1.weight`，形状 `[6,1,5,5]`，是学到的权重，不是示意图。

### 2. 误判样本要能回查原图

```python
from src.data import get_raw_dataset_by_split

raw = get_raw_dataset_by_split("test")     # 0—1 像素，未标准化，可直接 imshow
img, label = raw[test_index]
```

用带标准化的数据集直接 `imshow` 会变成一堆负数和黑块，这是常见翻车点。
