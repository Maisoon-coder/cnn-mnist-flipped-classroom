| Python | **3.11 — 3.14 均可**；若要新装，选 **3.12** | 3.12 的生态兼容性最稳；本机 3.14 也能装 torch 2.15，不必重装 Python |

| numpy | 跟随 torch 依赖自动装，不手动指定 | 版本冲突多半来自手动装 numpy |
| matplotlib | 可选，**只有组员 5 需要** | 画曲线与特征图；不画图的人不用装 |
| tqdm | 可选 | 训练进度条，纯体验，不影响结果 |

**核心原则：三个人装同一套版本，先装的人定版本，后装的人照抄。**

## 三、建议的安装方式（Windows）

### 3.1 用虚拟环境，不装进系统 Python

在项目根目录执行，得到一个 `.venv` 文件夹（已在 `.gitignore` 中忽略，不会进仓库）：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
```

以后每次开工前先激活：

```powershell
.\.venv\Scripts\Activate.ps1
```

> 若提示"禁止运行脚本"，执行一次：
> `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`

### 3.2 装 torch（CPU 版）

```powershell
# 国内网络建议加清华镜像
python -m pip install torch torchvision -i https://pypi.tuna.tsinghua.edu.cn/simple
```

Windows 上从 PyPI 装的 torch 默认就是 CPU 版，不需要额外指定 `--index-url` 切 CUDA。

### 3.3 只给组员 5 加装绘图库

```powershell
python -m pip install matplotlib -i https://pypi.tuna.tsinghua.edu.cn/simple
```

## 四、版本锁定规则（对应修订清单 R-03）

1. **D4 第一次完整跑通后立刻锁版本**，早于这个时间不写死版本号——避免写进一个没人验证过的版本。
2. 生成 `requirements.txt`：

```powershell
python -m pip freeze > requirements.txt
```

3. 之后**任何人不得单独升级** torch / torchvision / numpy。需要升级时必须全组一起升级并重跑双方实验，旧结果作废。
4. 权重加载统一写法，避免 `weights_only` 版本差异导致现场打不开：

```python
state = torch.load(ckpt_path, map_location="cpu", weights_only=False)
```

## 五、环境自检

项目里已提供脚本 `scripts/check_env.py`（**只读检查，不会安装任何东西**）：

```powershell
python scripts/check_env.py              # 基础检查
python scripts/check_env.py --download   # 额外确认 MNIST 能加载
```

脚本会检查 11 项：Python 版本、平台、架构、torch、torchvision、numpy、matplotlib、CUDA、线程数、张量运算、卷积前向、损失与反向传播、参数量是否符合 203,530 / 61,706、MNIST 是否可用。

**通过标准**：最后一行输出 `RESULT: PASS`。

其中两项特别有用：

- **conv2d fwd**：应输出 `(1,1,28,28) -> (1, 6, 28, 28)`，说明卷积输出尺寸算对了；
- **param count**：应输出 `FC=203530 CNN=61706 match_expected=True`，说明模型实现与方案的参数量一致。

## 八、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `ModuleNotFoundError: No module named 'torch'` | 没激活虚拟环境，或装到了另一个 Python | 先确认 `where python` 指向 `.venv`，再装 |
| 安装时报连接超时 / 连接被重置 | 国内网络访问 PyPI 不稳 | 加 `-i https://pypi.tuna.tsinghua.edu.cn/simple` 重试 |
| `pip` 提示找不到匹配版本 | Python 版本过新或过旧，没有对应轮子 | 换 Python 3.12；或先 `pip install --upgrade pip` |
| 装完 import 报 numpy 版本冲突 | 手动装过 numpy | 卸载后让 torch 自动带出依赖：`pip install --force-reinstall torch` |
| 权重加载报 `UnpicklingError` / 参数变更 | torch 版本不同 | 用 `weights_only=False`，并把版本统一 |
| PowerShell 禁止运行脚本 | 执行策略限制 | `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` |
| 训练时 `mat1 and mat2 shapes cannot be multiplied` | 不是环境问题 | 是 Flatten 后维度算错，检查是否 400 |
